# India Rain Radar

Mobile-first GitHub Pages client for the append-only radar archive generated by
`radar_ingest.py` in the ILDN workspace. The client tries the JASMIN GWS mirror
first and the University of Reading mirror second.

The upstream composite currently contains nominal ten-minute frames. The page
checks for updates every five minutes and offers a five-minute slider; midpoint
positions are visibly labelled cross-fades between adjacent genuine frames.

Data attribution and operational caveats are deliberately visible in the page.
Visitor Badge Reloaded provides the cookie-free visible request count. The radar
page increments it once; the portfolio badge uses the same counter in documented
read-only (`hit=false`) mode.
